# 侧边栏美化设计方案

## 目标
美化主页、说说、朋友们三个页面的右侧边栏，从当前方块样式升级为更有设计感的视觉效果。

## 当前状态
三个侧边栏组件使用统一样式：
- `RightHomeSidebar.astro` - 主页
- `RightMurmurSidebar.astro` - 说说
- `RightFriendsSidebar.astro` - 朋友们

当前样式特点：
- 圆角 `0.6rem`（约 10px）
- 1px 细边框
- 纯色背景
- 标题下划线分隔

---

## 设计方案

### 方案 A：玻璃拟态（Glassmorphism）
**风格**：现代、通透、有层次感

```
┌─────────────────────┐
│ ╭─────────────────╮ │
│ │  碎碎念统计      │ │
│ │  ───────────────│ │
│ │  12 条说说       │ │
│ ╰─────────────────╯ │
│                     │
│ ╭─────────────────╮ │
│ │  一言           │ │
│ │  ───────────────│ │
│ │  "人生如逆旅"   │ │
│ ╰─────────────────╯ │
└─────────────────────┘
```

**CSS 要点**：
- `backdrop-filter: blur(12px)` 毛玻璃效果
- `background: rgba(255,255,255,0.08)` 半透明背景
- `border: 1px solid rgba(255,255,255,0.15)` 微光边框
- `box-shadow: 0 4px 24px rgba(0,0,0,0.1)` 柔和阴影
- 圆角增大到 `1rem`

**优点**：现代感强，与二次元背景图呼应
**缺点**：暗色模式下需要调整透明度

---

### 方案 B：卡片悬浮（Floating Cards）
**风格**：立体、有呼吸感、层次分明

```
   ┌─────────────────┐
   │  碎碎念统计     │  ↑
   │  ────────────── │  │ 微上浮
   │  12 条说说      │  ↓
   └─────────────────┘
      └── 阴影

   ┌─────────────────┐
   │  一言           │
   │  ────────────── │
   │  "人生如逆旅"   │
   └─────────────────┘
```

**CSS 要点**：
- `border-radius: 1.2rem` 大圆角
- `box-shadow: 0 8px 32px rgba(0,0,0,0.12)` 立体阴影
- `transform: translateY(0)` → hover 时 `-4px`
- 卡片间距增大到 `1.5rem`
- 去掉边框，纯阴影营造边界

**优点**：简洁大气，视觉层次清晰
**缺点**：阴影在暗色模式需调淡

---

### 方案 C：渐变边框（Gradient Border）
**风格**：精致、有色彩、个性化

```
┌─────────────────────┐
│ ╔═════════════════╗ │
│ ║  碎碎念统计      ║ │
│ ║  ───────────────║ │
│ ║  12 条说说       ║ │
│ ╚═════════════════╝ │
└─────────────────────┘
    渐变边框（蓝→紫）
```

**CSS 要点**：
- 使用伪元素实现渐变边框
- `border-radius: 0.8rem`
- 渐变色：`linear-gradient(135deg, #667eea, #764ba2)`
- 内部卡片保持纯色背景
- hover 时渐变角度旋转

**优点**：有辨识度，色彩丰富
**缺点**：实现稍复杂，需注意暗色模式

---

### 方案 D：圆角胶囊（Pill Style）
**风格**：圆润、可爱、轻松

```
  ╭─────────────────╮
  │  ● 碎碎念统计   │
  │  ─ ─ ─ ─ ─ ─ ─  │
  │  12 条说说      │
  ╰─────────────────╯

  ╭─────────────────╮
  │  ● 一言         │
  │  ─ ─ ─ ─ ─ ─ ─  │
  │  "人生如逆旅"   │
  ╰─────────────────╯
```

**CSS 要点**：
- `border-radius: 1.5rem` 超大圆角（胶囊形）
- 标题前加圆点装饰 `::before { content: "●" }`
- 虚线分隔 `border-bottom: 2px dashed`
- 柔和背景色 `background: var(--charm-contrast-color-2)`
- 无边框

**优点**：可爱轻松，适合博客氛围
**缺点**：可能过于圆润

---

### 方案 E：混合方案（推荐）
结合多种效果，不同页面用不同风格：

| 页面 | 风格 | 特点 |
|------|------|------|
| 主页 | 玻璃拟态 | 与背景图融合，通透 |
| 说说 | 卡片悬浮 | 内容多，需要层次 |
| 朋友们 | 渐变边框 | 友链主题，有活力 |

## 实现步骤

### Step 1：创建通用样式文件
创建 `playground/src/styles/sidebar-widgets.css`，定义 CSS 变量和通用类：
- `.widget-glass` - 玻璃拟态
- `.widget-float` - 卡片悬浮
- `.widget-gradient` - 渐变边框
- `.widget-pill` - 圆角胶囊

### Step 2：更新三个侧边栏组件
- `RightHomeSidebar.astro` → 应用 `.widget-glass`
- `RightMurmurSidebar.astro` → 应用 `.widget-float`
- `RightFriendsSidebar.astro` → 应用 `.widget-gradient`

### Step 3：调整暗色模式
在 `custom-charm.css` 中添加暗色模式适配：
- 调整透明度
- 调整阴影颜色
- 调整渐变亮度

### Step 4：微调各 widget 内部样式
- 标题样式统一
- 内容间距调整
- hover 效果增强
